# Finixcode Task

A frontend implementation of a sports event platform UI, created for a job application task. Built with Next.js, Typescript and Tailwind CSS.

## Live Demo

[View Live Demo](https://finixcode-mhn.vercel.app)

## Project Overview

This is a frontend-only implementation focusing on UI/UX design and somewhat a responsive layout. The project demonstrates skills in:

- Component architecture
- Responsive design (To a very limited extent)
- UI state management
- Modern React patterns with Next.js

## UI Features

- Interactive event details page
- Responsive layouts for all screen sizes
- Tab-based navigation
- Modal windows for payment methods
- Player listings and comments section

## Tech Stack

- **Framework**: Next.js
- **Styling**: Tailwind CSS
- **Language**: TypeScript
- **Deployment**: Vercel

## Running Locally

1. Clone the repository

```bash
git clone https://github.com/yourusername/finixcode_task.git
cd finixcode_task
```

2. Install dependencies

```bash
npm install
# or
yarn install
```

3. Start the development server

```bash
npm run dev
# or
yarn dev
```

4. Open [http://localhost:3000](http://localhost:3000) in your browser

## Project Structure

- `app/components/` - UI components for the application
- `public/` - Static assets and SVG icons
- `app/` - Next.js app structure and global styles
